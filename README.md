# Chemical-Reaction-Protege-Anthology

A web-based system to predict chemical reactions using Flask and Protege ontology.

## Features
- Input chemical compounds and predict reaction outcomes.
- Integration with ontology tools for reasoning.
- User-friendly interface.

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Ontology: Protege with OWL files
